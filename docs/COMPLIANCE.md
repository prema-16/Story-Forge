# Compliance Framework Guide

StoryForge AI V3 maintains compliance across GDPR, SOC 2 Type II, and ISO 27001.

## Supported Frameworks
- **GDPR**: DSR processing (Erasure, Access, Portability) with 30-day SLA enforcement
- **SOC 2 Type II**: CC6, CC7, CC8, A1 controls mapped and verified
- **ISO 27001**: A.8, A.9, A.12, A.17 controls verified
- **Consent Manager**: Version-tracked granular opt-in/opt-out management
