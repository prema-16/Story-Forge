# Multi-Platform Publishing Engine Documentation

## Platforms Supported
- **YouTube**: OAuth Data API v3 integration with playlist, tag, and thumbnail upload.
- **TikTok**: Creator Hub API publishing for shortform video.
- **Instagram Reels**: Graph API video publish.
- **X (Twitter) & Facebook**: Media API publishing.
- **LinkedIn & Vimeo**: Direct OAuth publishing.
- **Custom Webhooks**: Outbound HTTP Webhook payloads.
