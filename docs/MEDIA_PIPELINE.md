# Media Processing Pipeline Documentation

## Overview
Processes audio, video, and subtitle streams prior to encoding and publishing.

## Capabilities
- **LUFS Audio Normalization**: Normalizes narration and background audio to YouTube -14 LUFS standard.
- **Subtitle Burning**: Renders SRT/VTT captions directly into video frames.
- **Waveform Extraction**: Generates 100-point audio waveforms for studio visualization.
