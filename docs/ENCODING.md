# Encoding System & Quality Presets Documentation

## Export Formats Supported
- **Video Containers**: MP4 (H.264), H.265 / HEVC, WebM (VP9), MOV (ProRes), Animated GIF.
- **Frame Sequences**: PNG Sequence, JPEG Sequence.
- **Audio Exports**: MP3, WAV.
- **Subtitles & Archives**: SRT, VTT, JSON Package, ZIP Archive.

## Quality Presets
- **Draft**: CRF 28, 2M Bitrate, Ultrafast preset.
- **Standard**: CRF 23, 8M Bitrate, Medium preset.
- **High**: CRF 18, 16M Bitrate, Slow preset.
- **Lossless**: CRF 0, 50M Bitrate, Veryslow preset.
