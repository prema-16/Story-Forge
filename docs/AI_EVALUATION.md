# AI Evaluation Platform Guide

StoryForge AI V3 includes continuous quality evaluation for AI prompt outputs, video rendering, and SEO metadata.

## Evaluation Dimensions
- **Prompt Scoring**: Faithfulness, Relevance, Safety, Creativity, Coherence
- **Video Quality**: Resolution, Bitrate, Scene Pacing, Audio Clarity
- **Thumbnail CTR**: Visual contrast, text legibility, face detection
- **Hallucination Detection**: Fact-grounding verification against reference prompt facts
- **Golden Dataset**: Automated regression runner against ground-truth test cases
