# AI Playground, Benchmark Engine & Sandbox Documentation

## Overview
Allows creators and developers to test, compare, and benchmark providers, prompts, latency, costs, and quality scores.

## Features
- **AI Benchmark Engine**: Compares OpenAI vs Claude vs Gemini vs Groq on token throughput and response latency.
- **AI Sandbox**: Interactive prompt testing testbed with real-time output preview.
- **Smart Cache**: Semantic output cache reducing duplicate prompt API costs.
