# Studio UI, Command Palette & Keyboard Shortcuts Documentation

## Workspace Layout
Dockable Premiere Pro / DaVinci Resolve inspired dark theme layout:
- **Left Sidebar**: Asset Library (DAM) & AI Tools
- **Center Stage**: Real-Time Video Preview Player
- **Bottom Panel**: Multi-Track Timeline Engine
- **Right Sidebar**: Inspector & AI Suggestions

## Global Keybindings
- `Space`: Play / Pause Toggle
- `Cmd + Z`: Undo
- `Cmd + Shift + Z`: Redo
- `Cmd + S`: Save / Create Snapshot
- `Cmd + K`: Open Command Palette Search
- `Delete` / `Backspace`: Delete Selected Clip
- `S`: Split Clip at Playhead
- `M`: Add Marker at Playhead
- `Left / Right Arrow`: Step 1 Frame Back / Forward
