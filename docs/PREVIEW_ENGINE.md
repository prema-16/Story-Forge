# Video Preview Engine Documentation

## Overview
Real-time HTML5 video and WebAudio preview player with synced subtitle captions.

## Features
- **Timecode Overlay**: Standard SMPTE timecode display.
- **Frame Stepping**: Precision single-frame and 10-frame stepping (`ChevronLeft` / `ChevronRight`).
- **Safe Margins Overlay**: Toggleable 90% Action Safe and 80% Title Safe boundary boxes.
- **Playback Speed**: Adjustable speed rates (`0.25x`, `0.5x`, `1.0x`, `1.5x`, `2.0x`).
