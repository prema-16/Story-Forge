# AI Shorts Studio REST API Reference

Base Endpoint: `/api/shorts`

## Endpoints Summary

- `POST /api/shorts/generate` — Create new short project.
- `POST /api/shorts/hooks` — Generate 10+ hook variations.
- `POST /api/shorts/virality-score` — Compute Virality Score & Retention Prediction.
- `POST /api/shorts/clip-finder` — Extract 10/20/50 viral clips from long video.
- `POST /api/shorts/batch` — Trigger batch generation queue (10 to 500 shorts).
- `POST /api/shorts/publish` — Multi-platform publishing across 9 platforms.
- `GET /api/shorts/analytics` — Shorts performance telemetry & RPM tracking.
